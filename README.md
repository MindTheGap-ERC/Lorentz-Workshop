## Editing

`Application.Rmd` is in the R Markdown format, which is a glorified markdown format that allows a few extras. It can be edited as text and rendered to docx or pdf at the end. You can edit it in any text editor. References can be added in BibTeX to `references.bib`, they will be formatted upon rendering.
