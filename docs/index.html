0.1 Introduction

Welcome to the online materials for the workshop “Bridging Stratigraphic Paleobiology and Phylogenetics”. This page collects all contents (code, text, references, and notes) used during the workshop.

0.2 Installation instructions

Software for phylogenetic inference is spread over multiple software systems. We will use:

  • git and GitHub to exchange code and collaborate on its annotation

  • Julia for stratigraphic forward simulations

  • R for phylogenetic simulations and to build models of stratigraphic paleobiology

  • revbayes or BEAST for phylogenetic inference

  • FigTree and Tracer for the visualization of posteriors

  • An IDE (integrated development environment) of your choice (e.g., VSCode or RStudio) to conveniently interact with this software.

0.2.1 Git and GitHub - optional

Why yet another tool, my nerds? Git is a tool for version control, primarily for code but it works for any text-based files. For us, the most important use is that it will give us a “track-change” mode and we will be able to share everyone’s contributions with all participants live. This workshop’s purpose is not teaching git, so if you want to keep your mental resources for the science, you will be able to work through the week without using it. However, the goal we want to promote is better reproducibility of phylo/strat projects and better interaction between users and developers. For these goals, using git is essential and we want to support our community memebers in adopting it. So if you haven’t had experience with git before and you feel unsure about using it, please reach out to one of the organizers or git heros we will mark among the participants and we’ll give you a run down.

0.2.1.1 Installation

0.2.1.1.1 Get a GitHub account

Please follow the instructions on GitHub’s own Getting started page. Choose a free plan. Please note that you will need to verify your email address as one of the steps. Secondly, you will be given several options for two-factor authentication (2FA): each of them should work; choose the one that is the most familiar (the lear unfamiliar) to you. You can install the GitHub mobile app on your phone, but it is not indispensable.

0.2.1.1.2 Install a git client

There exist multiple git clients and we won’t be experienced in using all of them ourselves. The essentials are:

  1. GitHub Desktop - a graphic user interface available for Windows and Mac, recommended for first-time users
  2. git - a command line interface typically shipped with any Linux, can be installed on MacOS and PowerShell - recommended if you are otherwise accustomed to using the CLI

Configuration instructions will depend on which one you choose, but we focus here on first-time users, so assuming you use GitHub Desktop, you will need to sign into your GitHub account to be able to contribute.

0.2.1.1.3 Using git to collaborate

If you want to contribute code or text directly from your computer to the workshop’s open book, you will need to use operations such as switching between branches, pulling other people’s contributions, commiting your changes, and pushing your changes. You can collaborate with someone and do this together, or take a look at the instructions online and try on your own.

Tip

Remember: as long as you work on a separate branch, you can’t break anything - don’t hesitate to experiment, this is how you learn.

0.2.2 Julia

To install Julia, please go to the Julia Language Downloads page. It will automatically detect your system and provide a link to the correct installation file. It will install juliaup, which is a tool for managing Julia installations on your system and takes care of any version issues.

Once you have installed juliaup, you can easily install different version of Julia. All Julia code was tested using Julia version 1.13.0, which you can install using

juliaup add 1.13.0
juliaup default 1.13.0

0.2.3 Installing R, R Studio, and packages

R can be directly installed from CRAN (the comprehensive R archive network) here. Choose the latest version for your operating system and follow the installation instructions. At the time of the workshop, the latest version is R 4.6.1 (“Happy Hop”).

You can interact with R using the IDE of your choice. Most R users are familiar with RStudio, which provides a lot of convenient functionality. R Studio can be downloaded from Posit here.

Once you have downloaded R, install all required packages by running the following code in R (e.g., in your R Studio console):

install.packages("remotes")
remotes::install_github("fossilsim/morphsim")
remotes::install_github("fossilsim/FossilSim")
remotes::install_github("MindTheGap-ERC/admtools")
remotes::install_github("MindTheGap-ERC/StratPal")
install.packages("TreeSim")
